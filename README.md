# Lenovo Legion Y7000 2021 (i5 version) Hackintosh EFI
This EFI is made with the 1401 tool. I’ve made a basic fix for the Wi‑Fi issue for now; this is the best I can do since I’m not very experienced with Hackintosh troubleshooting.

Most features work for the time being. From my testing, the microphone does not function, and Siri cannot be invoked.
USB-A ports do not work; USB flash drives will not be detected when plugged in, though wired mice and wired keyboards function normally. 
Type‑C ports are usable and can read data from USB drives.
Apple-exclusive features such as AirDrop are unavailable — this is a classic Hackintosh limitation.

## Specifications
- **Processor**: Intel Core i5-11400H, 6 cores / 12 threads, base 2.7GHz, max boost 4.5GHz, 12MB L3 Cache, Tiger Lake-H (10nm SuperFin)
- **Chipset**: Intel HM570
- **Discrete GPU**: NVIDIA GeForce RTX 3050 Laptop GPU, 4GB GDDR6, 128-bit, 95W TGP, supports Hybrid Mode & Dedicated GPU Mode
- **Memory**: 16GB (8GB × 2) DDR4 3200MHz, 2 × SO-DIMM slots, upgradable up to 64GB
- **Storage**: 512GB PCIe 4.0 NVMe M.2 2280 SSD; dual M.2 slots, the second slot also supports PCIe 4.0
  > Original SSD models vary by batch: Samsung PM9A1 / Micron 2300 / WD SN730(my SSD is Sansung SSD)
- **Display**: 15.6-inch FHD (1920×1080) IPS, 100% sRGB, 300 nits, 60Hz, DC dimming, 16:9
- **Battery**: 80Wh
- **Power Adapter**: 230W barrel charger
- **Cooling System**: FrostBlade Pro 3.0, dual fans + multiple heat pipes
- **Wireless**: Intel AX201 Wi‑Fi 6 + Bluetooth 5.1
- **Camera**: 720P HD webcam with physical privacy shutter
- **Keyboard**: White backlit keyboard with numeric keypad
- **Ports**:
  - 2 × Thunderbolt 4
  - 4 × USB 3.2 Gen1-A
  - HDMI 2.1
  - RJ45 Gigabit Ethernet
  - 3.5mm combo audio jack
  - Barrel power port
- **Dimensions**: 362.56 × 260.61 × 22.5–25.75 mm
- **Weight**: Approx. 2.4 kg
